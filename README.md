# СЛЕД — память, которую передают (версия для республиканского этапа)

## Запуск
1. Распакуйте архив **целиком** в папку (из архива напрямую не запускать).
2. Дважды щёлкните `index.html` (Chrome или Edge, Windows 10 и новее).
3. Интернет, сервер, API-ключи и платные сервисы не нужны. Ссылки на источники открываются только при подключении к интернету.
4. При каждом запуске прогресс начинается заново (ничего не сохраняется, личные данные не собираются).

## Экран и телефоны
Сайт сам определяет размер окна и устройство (`layout.js`):
- **Компьютер, ноутбук, планшет в ландшафте** — сцена целиком помещается в окно при любом соотношении сторон; вокруг сцены дорисованы стена и пол, чёрных полос нет; интерфейс привязан к сцене.
- **Телефон и планшет в портрете** — сверху сцена-«шапка», под ней подсказка и крупные кнопки разделов (Картотека, Карта, Нить памяти, Журнал, Викторина, Лица памяти). Окна открываются на весь экран; доска «Нить памяти» превращается в вертикальный список.
- **Телефон в ландшафте** — сцена слева, колонка значков разделов справа.
- Карта на сенсорном экране: перетаскивание одним пальцем, масштаб — двумя (щипок) или кнопками «+ / −».
- Размер окна и поворот телефона подхватываются сразу, перезагружать не нужно.

## Файлы
- `index.html` — комната и оформление; `ext.css` — оформление викторины и галереи.
- `layout.js` — подстройка под экран; `app.js` — основная логика; `data.js`, `history.js`, `map-data.js` — данные и карта.
- `i18n.js`, `i18n-data.js` — переводы (ключ — русский текст). Названия источников теперь тоже переведены.
- `quiz.js` — викторина (тексты вопросов на трёх языках лежат прямо в файле).
- `faces.js` — галерея «Лица памяти» (данные людей — массив `PEOPLE`).
- `img/` — изображения сайта. В `img/faces/` лежат облегчённые иллюстрации для карточек и полноразмерные копии `имя-full.jpg`, открывающиеся по клику. Иллюстрации сгенерированы ИИ и не показывают достоверную внешность названных людей.

## Как добавить викторину по папке (Слуцк, Новогрудок, Минск)
Движок уже поддерживает несколько викторин. В конце `quiz.js` (или в новом файле, подключённом после `quiz.js`) добавьте:

```js
QUIZ.register({
  id: 'slutsk', order: 1,
  title: {ru: '…', be: '…', en: '…'},
  intro: {ru: '…', be: '…', en: '…'},
  questions: [
    { s: ['rcnt'],               // ключи источников из SRC (data.js) или {n:'название', u:'https://…'}
      ru: {q:'…', o:['ПРАВИЛЬНЫЙ ответ','вариант 2','вариант 3','вариант 4'], e:'пояснение'},
      be: {…}, en: {…} }
  ]
});
```
Правильный ответ всегда первый в списке `o`; при показе варианты перемешиваются. Если викторин больше одной, значок «?» открывает список викторин.

## Изображения в «Лицах памяти»
В этой версии карточки используют условные ИИ-иллюстрации. Подпись в каждой карточке сообщает, что это не архивная фотография и не достоверное изображение человека. Чтобы заменить их на подлинные портреты, сначала получите файл и разрешение правообладателя, положите версию для карточки и полноразмерную копию в `img/faces/`, затем обновите у нужного человека `photo.file` и `photo.full` в `faces.js`. Укажите автора/архив, условия использования и ссылку на страницу-источник; не называйте иллюстрацию фотографией.
