ЗАПУСК: распакуйте архив целиком и дважды щёлкните index.html (Windows 10+, интернет не нужен; ссылки на источники открываются при наличии интернета). При каждом запуске прогресс начинается заново.
ФОТО: папка img. Для каждого снимка две копии: name.jpg (до 320 КБ, для сайта) и name-full.jpg (полный размер, открывается при увеличении по клику). Привязка этапов к фото — в конце data.js; фото на карте — поля ph в history.js. Если файла нет, показывается заглушка img/placeholder.jpg.
ДАННЫЕ: сведения и ссылки — data.js; карта (Natural Earth) — map-data.js; хронология, фронты, стрелки наступления (ARR), бои, деревни/лагеря/гетто, города, железная дорога — history.js (линии фронта и стрелки приблизительные).
О ПРОЕКТЕ: скрытая кнопка «i» в правом нижнем углу; текст — window.ABOUT в data.js.
ЯЗЫКИ: кнопки RU / BE / EN вверху справа. Переводы — в i18n-data.js (ключ — русский текст), логика — в i18n.js. Названия источников (ссылки) не переводятся.
СТОЛИЦЫ: звёздочкой отмечены Минск, Москва, Варшава, Берлин, Киев; список — CAP и CAPN в history.js.
